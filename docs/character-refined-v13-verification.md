# v13：头身比例与裤腿细化

沿用 [AI 设计参考](references/character-refined-v12-concept.png)，调整三种人物的头身比例，延长腿部与衣身。保留三套造型、服装配色和背包。

| 造型 | 头部倍率 v12 → v13 | 衣身倍率 | 腿部倍率 |
| --- | --- | --- | --- |
| A | 1 → 0.91 | 1 → 1.08 | 1 → 1.16 |
| B | 0.93 → 0.87 | 1.04 → 1.10 | 1.13 → 1.25 |
| C | 0.88 → 0.83 | 1.10 → 1.14 | 1.23 → 1.34 |

裤腿增加局部斜向折痕，去除 A/B 独立膝部凸块。外侧缝线并入裤腿几何，使用相同蒙皮权重，随膝盖弯曲，不增加独立网格。裤腿的顶点采样有所增加。
